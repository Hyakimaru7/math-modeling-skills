原始附件保持原样；清洗和变换通过可重复运行的代码完成。先明确字段含义和观测单位，再处理数值。

## 数据工作

1. 检查表头、编码、重复键、缺失、非有限值、单位、时间频率及跨表连接关系。缺失值不等于零；异常处理记录判据、影响行数和来源。
2. 输出数据字典，给出关键变量的单位、取值域、数据来源和处理规则。派生特征写明计算方法。
3. 内置适配器读取工作区 data_file 指定的 CSV；格式见 [数据接口](references/data.md)。超出接口的输入在 custom.prepare 中处理。
4. 对预测任务提前确定训练、验证、测试时间边界。插补、缩放、特征选择和调参只在对应训练段拟合，未来可获得的外生变量才能用于外推。
5. 执行 `mm run <工作区> --until data`，检查 data/quality.json、data/processed.json 与原始文件能否对应。

不要为了跑通模型而默默删除不合预期的数据。无真实数据时，可以在明确授权的教学实验中生成模拟数据，注明生成机制和种子；真实赛题结果不得混入未声明的模拟观测。
