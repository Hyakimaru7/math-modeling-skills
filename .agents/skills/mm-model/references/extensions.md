# 其他题型的落地方式

这些方法需要宿主根据实际题目编写 custom 适配器。本项目提供执行和产物协议，不声称内置完整算法库。

- 综合评价：定义指标意义和正负方向，解释标准化与权重来源；对冗余指标、权重扰动及排名稳定性做检查。熵权反映样本离散性，不自动代表实际重要程度。
- 多目标优化：定义冲突目标、约束和决策偏好；输出 Pareto 候选及选择依据，不把任意加权和当作唯一标准答案。随机方法保存种子和计算预算。
- 微分方程：明确状态量、守恒关系、初始与边界条件，记录数值容差；用解析特例、步长变化和守恒检验验证。
- 排队与离散事件仿真：校准到达与服务分布，区分热身与稳态，使用独立重复；不把单次随机轨迹当成期望或置信区间。
- 机器学习：基线、分组/时间划分、训练内预处理、调参预算和适当指标是必要设计；特征解释不能自动变成因果结论。

每个小问必须提供可运行 solve 与非空 validate，代码输出进入同一结果、图表和论文链路。
