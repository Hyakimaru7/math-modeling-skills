# 预测与评价设计

明确预测对象、频率、起点、时域，以及起点时可获得的信息。将最终测试集留出；模型选择、缩放和特征构造只在训练内拟合。时间数据使用滚动或扩展窗口，不能随机打散制造未来泄漏。

设置合理朴素基线，根据任务选 MAE、RMSE 或其他损失。跨不同尺度序列比较需要相应归一化；零值附近的百分比误差有问题。误差改善可为负，不隐藏模型不如基线的结果。

参考实现比较周朴素、趋势与趋势加周周期，在训练内三个扩展窗口选择模型。选定后只用最终留出期评价一次，再用全部观测拟合未来。未来点预测不等价于预测区间。外生变量、节假日、变化点、多序列、非日频数据应通过 custom 扩展。

参数求解来源：https://numpy.org/doc/stable/reference/generated/numpy.linalg.lstsq.html 。长期趋势外推与周期保持均属于需要审阅的模型假设。
