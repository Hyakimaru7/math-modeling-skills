# 优化模型选择

线性目标与线性约束、连续变量使用 LP；包含离散数量、选择或开关使用 MILP。排班、逻辑或路径问题也可在 custom 适配器选用合适的约束规划或路由求解器。存在非线性关系时需评估凸性、可微性、规模及可用算法。

变量先写意义、单位和域，之后写目标与约束。检查是否遗漏最低需求、容量、互斥、守恒与跨期传递。不要为满足代码接口删除原题约束。

参考适配器使用 SciPy milp，以负利润实现最大化。基线为可行贪心，LP 松弛提供适用上界，小规模整数域枚举作交叉核验；同步容量情景不能代表每类资源的独立边际分析。

验证重点：独立重算目标与约束、整数性、可行性、基线、上界与最优间隙。达到时间限制时保留求解状态；没有可行解时输出失败分析而不是目标值。

官方方法来源：https://docs.scipy.org/doc/scipy/reference/generated/scipy.optimize.milp.html 。真实问题可选 OR-Tools、Pyomo 等，但需要独立安装和适配，当前包不声称已提供所有后端。
