验证围绕原题要求和数学性质展开。程序成功退出只是运行完成的信号。

## 选择有意义的检查

- 优化：重算目标、逐项检查约束与整数域；与可行基线和适用的上下界比较。小规模问题可枚举或用另一种算法交叉验证。
- 预测：检查时间边界、训练内预处理和未来特征可获得性；重算误差，比较朴素基线；只评价真实观测对应的日期。
- 评价：检查指标方向、标准化、权重及排名对权重变化的敏感性。
- 机理或仿真：检查量纲、守恒、初始边界条件、解析或极限情况；随机仿真使用独立重复并说明不确定性。

选择与当前模型有关的检查；敏感性实验明确改变的参数、保持不变的条件和结果解释范围。失败或不可行结果同样记录，不用想象数据填充。

custom.validate 返回非空 checks；每项含 name、布尔 passed 和 detail。运行器从 checks 重新计算总体 passed，避免只相信标志。此函数尽量使用与 solve 不同的数学路径。

运行 `mm run <工作区> --until validate`。失败时查 validation.json 与 checks.csv，修正数据、模型或实现。通过后说明自动核验覆盖哪些条件、哪些解释仍需队员审阅。
