# 评测

运行 `python scripts/evaluate.py`。测试仅使用临时工作区，不改写交付案例。结果保存 evals/latest.json，包含每个任务状态和依赖版本。

## 自动评测维度

- 数学：整数已知最优值、利润比例变换、容量单调性、不可行状态；精确线性预测与独立拟合交叉核对。
- 数据：非有限数、单位缺失、产品重复、日期重复或缺口、JSON 非有限值、路径越界。
- 预测：对最终测试值施加巨大扰动后，训练期选模及 CV 分数应保持不变；伪造测试观测应验证失败。
- 工作流：断点恢复、全阶段缓存、输入变化失效、附件新增失效、正文局部重建、PDF 删除、图表损坏和产物篡改。
- 论文：数值绑定、未知来源、未回答小问、PDF 生成与自动审阅。
- 输入解释：小问依赖环、内置题型不支持的任务、未决事项、非空目录保护。

验收不以正文长度或模型复杂度为标准。独立环境全链复现与模型结果合理性需要分别验证。

## 宿主级前向评测

evals/skill-prompts.jsonl 给出应该/不应该触发的自然语言任务、预期技能和可观察验收条件。实际评测时，将当前 skills 包和最小原始文件交给独立会话；不给预期答案或已知缺陷。比较同一模型、相似预算下有无 skills 的题意覆盖、代码执行、正确性、重复数值一致性与耗时。

这些是提供的评测任务，不是已经测得的 LLM 路由准确率或获奖概率。真实新题的数学正确性还需要原题核验和专家判断。
