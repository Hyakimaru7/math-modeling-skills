# 一手来源

下列页面在项目构建时打开核对，访问日期为 2026-11-05。示例论文中的来源仍保留 opened_by_agent，未冒充人工作者核验。

- OpenAI，Build skills：https://learn.chatgpt.com/docs/build-skills 。技能目录、发现和资源组织。
- OpenAI，Testing Agent Skills Systematically with Evals：https://developers.openai.com/blog/eval-skills 。小型行为评测与可观察验收。
- SciPy，milp：https://docs.scipy.org/doc/scipy/reference/generated/scipy.optimize.milp.html 。线性整数目标、约束、状态和间隙。
- NumPy，lstsq：https://numpy.org/doc/stable/reference/generated/numpy.linalg.lstsq.html 。线性最小二乘求解。
- 全国大学生数学建模竞赛，Regulations on the Use of Artificial Intelligence Tools (Trial for 2026)：https://www.mcm.edu.cn/html_en/node/532f38e63cfa84145697e2678575ba0a.html 。人工复核及使用记录要求；未来比赛须重新核对当年规则。
- COMAP，MCM/ICM Instructions：https://www.contest.comap.org/undergraduate/contests/mcm/instructions.php 。赛事说明随年份更新，不能将当前配置固化为所有年度要求。

这些页面说明工具与规则，不是演示数据的来源。演示数据来源在各案例中单独声明。
